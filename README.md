
# AI-Powered Smart Attendance System

## Project Overview
An attendance management system that uses face recognition,
QR verification, and liveness detection.

## Core Features
- Automated student identification
- QR-based fallback verification
- Liveness and anti-spoofing checks
- Automatic attendance recording
- Duplicate attendance prevention
- Teacher dashboard and attendance reports

## Technology Stack
- Python
- OpenCV
- Pretrained face-recognition model
- SQLite
- Flask
- HTML, CSS, JavaScript
